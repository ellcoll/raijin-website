# Raijin BJJ Hanoi Website

A clean, responsive, multi-page static website built for **Raijin BJJ Hanoi**, a Brazilian Jiu-Jitsu gym in Hanoi, Vietnam. Built with vanilla HTML5, CSS3, and JavaScript with zero external frameworks or build dependencies.
